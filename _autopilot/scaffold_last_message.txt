Created a standalone repo in `/home/alireza/research-autopilot/generated_projects/librispeech-mrm-wav2vec2` with:

- Data
  - Smoke (fast, default): synthetic speech-like wavs + manifests + deterministic corrupted test manifests (`data/manifests/*`), generated by `python -m librispeech_mrm.cli --config configs/smoke.yaml data`
  - Full (OpenSLR): sequential download + checksum verification (parses OpenSLR MD5s where available) + extraction + LibriSpeech manifests + deterministic corrupted test manifests + deterministic labeled subsets (1h/10h/100h) via `configs/full.yaml` and `data.profile: openslr`
- Training (PyTorch) with reproducibility controls (seed + deterministic flags)
  - Supervised baseline: log-mel + Conformer + CTC + SpecAugment
  - SSL baseline: wav2vec2-style pretraining with standard time masking only
  - Proposed MRM + ablations (as in the plan) via masking config knobs (feature mask on/off, curriculum on/off)
  - Robustness ablation supported via optional noise+RIR augmentation toggle in fine-tuning (and supervised) runs
- Evaluation + reporting
  - Writes `artifacts/results.json` and `artifacts/report.md` (includes bootstrap WER CIs, and pulls in per-run `train_summary.json`)

Key entrypoints / files:
- `Makefile` targets: `setup`, `data`, `train`, `eval`, `report`, `all`
- Venv bootstrap (PEP 668 safe, no `ensurepip` required): `scripts/bootstrap_venv.sh`
- CLI: `src/librispeech_mrm/cli.py` (subcommands: `data`, `train`, `pretrain`, `finetune`, `eval`, `report`)
- Default fast config: `configs/smoke.yaml`
- Full experiment template: `configs/full.yaml`

Run (smoke, end-to-end):
```bash
make all
```

Run (full template):
```bash
CONFIG=configs/full.yaml make data
CONFIG=configs/full.yaml make train
CONFIG=configs/full.yaml make eval
CONFIG=configs/full.yaml make report
```
